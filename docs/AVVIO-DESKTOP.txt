STA CALCOLO - Suite WPF / MVVM

Avvio: aprire STA.Calcolo.Desktop.exe.
Setup: Windows x64, runtime incluso; aggiornamenti automatici da GitHub.
Pacchetto portabile framework-dependent: richiede runtime .NET Desktop 10.

La finestra principale richiama materiali, carichi neve/vento/sisma,
sezioni, trefolature, travi e plinti. Le finestre conservano il progetto
nella sessione. Salvare in JSON prima di uscire dall'applicazione.

Per una prima prova dei plinti MIDAS: aprire "Plinti · reazioni e MIDAS",
premere "Carica esempio", quindi "Calcola". I dati sono dimostrativi.
Le chiavi API rimangono in memoria e non sono salvate nei documenti.

Per le travi: salvare un progetto dall'editor sezioni e uno dall'editor
trefolature, quindi importarli nella finestra "Travi prefabbricate".
Questa finestra organizza i dati; non esegue una verifica completa della trave.

I moduli storici mantengono le formule e i limiti descritti nell'interfaccia.
La migrazione a .NET 10 non costituisce aggiornamento normativo delle formule.
I vecchi file .staxml e le integrazioni Word/Excel non sono importati dalla suite.
Consultare Guida-migrazione.md per la mappatura completa e i limiti.
